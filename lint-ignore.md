# `lint-ignore`

The CSS class 'lint-ignore' can be used to 
* prevent warning on a specific unused definition, when the [no-unused-dfns](no-unused-dfns) option of [lint](lint) is set. This class attribute has to be added to the `<dfn>` element.
* prevent warning on a link to an informative definition in a normative section, when the [informative-dfn](informative-dfn) option of [lint](lint) is set. This class attribute has to be added to the link.
