# Dark mode

To enable dark mode in your spec, add the following to the `<head>` of your document:

```html "example": "Enable dark mode styles"
<meta name="color-scheme" content="light dark">
```

**Note:** This is supported for W3C specs only, and makes use of [official dark.css in tr-design](https://www.w3.org/StyleSheets/TR/2021/README.html#dark).
